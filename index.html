Salud Vital

Sistema web para la gestión de pacientes

Bienvenido a Salud Vital

Salud Vital es un proyecto web orientado a la gestión de información básica de pacientes.

El sistema permite organizar la información de los pacientes de una manera sencilla y ordenada.

Gestión de pacientes

En este proyecto se pueden registrar datos básicos de los pacientes como nombre, dirección y teléfono.
